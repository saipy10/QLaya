## 0.4.0

* Initial release of `qlaya` for Dart / Flutter.
* Complete model registry (`QLayaModels`) with 10 user-selectable quantized model variants (INT8, INT4, FP16, student distillations).
* `QLayaClient` HTTP client for connecting to QLaya inference servers.
* Type definitions for `RoutingDecision`, `ModelSpec`, and inference options.
